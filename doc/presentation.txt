        DANS UN PREMIER TEMPS ... - Slide 3

- Différents degrés de plagiats existants : heavy, cut, light ...

- Focalistion sur les deux classes suivantes : plagiat ou pas plagiat

- Étant donné un texte, est il plagié ou pas ?



        MAIS COMMENT ? - Slide 4

- Un texte plagié a donc des caractéristiques qu'on est censé reconnaître ?

- Quelles sont elles ?

- En réalité, des modèles (algorithmes de classification) entraînés pour reconnaître ces caractéristiques



	PREPROCESSING - Slide 5
	
- Des caractéristiques basées essentiellement sur les mots du textes 

- Certaines informations du texte brut donc inutiles : espaces, caractères spéciaux

- Mêmes certains mots ayant une importance négligable : stopwords, lemmatisation

- Process de tokenization



	FEATURIZATION - Slide 6

- Des caractéritiques (features) qui seront extraites grâces à des featurizers 

- Un featurizer peut apprendre, du vocabulaire essentiellement (fit)

- Un featurizer peut transformer un texte brut en une matrice de features (transform)



	FEATURIZERS - Slide 7

- Différents featurizers

- Count Vector featurizer : fréquences des mots de chaque classe dans un texte
	Formule

- TF-IDF featurizer : limiter l'impact des mots très fréquents
	Formule



	CLASSIFICATION - Slide 8

- On peut à présent classifier les données extraites par les featurizers, grâce aux classifiers

- Un classifier peut être entraîné (fit)

- Un classifier peut être testé ou utilisé (predict)

- Un classifier peut être évalué (evaluate)



	CLASSIFIERS - Slide 9

- Différentes manières de classifier des features

- Naive Bayes : indépendance des features
	Formule

- Logistic regression : description briève
	Formule

- Perceptron : description briève
	Formule



	DETECTER DU PLAGIAT, PIPELINE - Slide 10

- Toute une chaine mise en place

- Du texte en entrée

- Des tokens du texte

- Des features extraits

- Une classe prédite
